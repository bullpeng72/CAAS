## 문제 해결 (Troubleshooting)

### 문제 1: "OPENAI_API_KEY not found"

**증상**:
```
Error: OPENAI_API_KEY not found in environment
```

**해결**:
```bash
# .env 파일 확인
cat .env
# OPENAI_API_KEY가 있는지 확인

# 없다면 추가
echo "OPENAI_API_KEY=sk-your-key" >> .env

# 또는 환경 변수 직접 설정
export OPENAI_API_KEY="sk-your-key"
```

---

### 문제 2: "ModuleNotFoundError: No module named 'crewai'"

**증상**:
```
ModuleNotFoundError: No module named 'crewai'
```

**해결**:
```bash
# 의존성 재설치
pip install -r requirements.txt

# 또는 crewai 직접 설치
pip install crewai
```

---

### 문제 3: "Traceability 83%" 오류

**증상**:
```
❌ Phase 2 failed: Traceability 83% (4/5 features mapped)
Feature f5 (할일 공유) → No mapping
```

**해결**:
```bash
# Golden Data 단순화
vim golden_data.json
# Feature f5 (할일 공유) 제거 또는 단순화

# Phase 2 재생성
caas generate-phase --phase 2 "..." --output . --force
```

---

### 문제 4: 코드 실행 시 에러

**증상**:
```
NameError: name 'TodoCRUDTool' is not defined
```

**해결**:
```bash
# 런타임 에러 자동 수정
python main.py 2> error.log

caas fix-runtime-error \
  --project . \
  --error-log error.log \
  --apply

# 재실행
python main.py
```
