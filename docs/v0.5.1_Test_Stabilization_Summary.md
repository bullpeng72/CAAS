## 4. 미해결 이슈 (Minor)

### 4.1 실패한 테스트 (5개)

**1. test_handles_no_keywords** (test_input_detector_unified.py)
- **현상**: Strategy 4가 빈 리스트 대신 기본 keyword 반환
- **원인**: Strategy 5 fallback이 더 안전하게 작동
- **심각도**: 🟡 Low (실제로 더 안전한 동작)
- **조치**: 테스트 기대값 수정 권장

**2. test_blog_search_scenario** (test_input_detector_unified.py)
- **현상**: 여러 strategy가 중복 검출 (1개 예상, 2개 실제)
- **원인**: Strategy 2 (INPUT_COLLECTION_PHRASES) + Strategy 4 (Keyword matching) 중복
- **심각도**: 🟡 Low (기능적으로 문제없음, 중복 제거됨)
- **조치**: 테스트 기대값 조정 권장

**3. test_handles_whitespace_variations** (test_code_quality_auto_fix.py)
- **현상**: "crew . kickoff()" 패턴 수정 실패
- **원인**: 정규식이 `crew.kickoff()`만 매칭 (점 사이 공백 미지원)
- **심각도**: 🟢 Very Low (실제로 이런 코드는 거의 없음)
- **조치**: 정규식 패턴 확장 또는 테스트 제거 권장

**4. test_logs_warning_on_fix_failure** (test_code_quality_auto_fix.py)
- **현상**: 로깅 테스트 실패 (caplog 인식 못함)
- **원인**: Logger 설정 문제
- **심각도**: 🟢 Very Low (로깅 자체는 작동, 테스트만 실패)
- **조치**: Logging fixture 설정 조정 권장

**5. test_complete_fix_workflow** (test_code_quality_auto_fix.py)
- **현상**: kickoff 수정 실패
- **원인**: #3과 동일 (whitespace 패턴)
- **심각도**: 🟡 Low
- **조치**: #3 해결 시 자동 해결됨
