### 1.2 Docstring Coverage

**기준**: 80% 이상

```python
# ❌ Bad: Docstring 없음
def create_todo(title, description):
    return {"title": title, "description": description}


# ✅ Good: Docstring 존재
def create_todo(title: str, description: str) -> dict:
    """
    Create a new todo item.

    Args:
        title: Todo title (1-200 characters)
        description: Todo description (optional)

    Returns:
        dict: Created todo object with id, title, description, created_at

    Raises:
        ValueError: If title is empty or too long
    """
    if not title or len(title) > 200:
        raise ValueError("Invalid title length")

    return {
        "id": 1,
        "title": title,
        "description": description,
        "created_at": "2026-02-14T15:30:00Z"
    }
```

## 3. 보안 스캔 (Bandit)

### 3.1 OWASP Top 10 체크

```bash
# Bandit 스캔
bandit -r . -f json -o security_report.json

# 또는 CAAS QA 스캔
caas qa security-scan --project ./project --owasp
```

**검출 항목**:
1. **SQL Injection**
   ```python
   # ❌ Bad
   query = f"SELECT * FROM todos WHERE id={todo_id}"
   cursor.execute(query)

   # ✅ Good
   query = "SELECT * FROM todos WHERE id=?"
   cursor.execute(query, (todo_id,))
   ```

2. **Hardcoded Secrets**
   ```python
   # ❌ Bad
   API_KEY = "sk-1234567890abcdef"

   # ✅ Good
   API_KEY = os.getenv("OPENAI_API_KEY")
   ```

3. **Command Injection**
   ```python
   # ❌ Bad
   os.system(f"rm -rf {user_input}")

   # ✅ Good
   import shutil
   shutil.rmtree(validated_path)
   ```

4. **Path Traversal**
   ```python
   # ❌ Bad
   with open(user_file_path) as f:
       content = f.read()

   # ✅ Good
   from pathlib import Path
   safe_path = Path(user_file_path).resolve()
   if not str(safe_path).startswith(str(ALLOWED_DIR)):
       raise ValueError("Access denied")
   with open(safe_path) as f:
       content = f.read()
   ```

### 6.2 메모리 최적화

```python
# ❌ Bad: 메모리 낭비
todos = []
for i in range(1000000):
    todos.append({"id": i, "title": f"Todo {i}"})


# ✅ Good: Generator 사용
def generate_todos():
    for i in range(1000000):
        yield {"id": i, "title": f"Todo {i}"}

for todo in generate_todos():
    process(todo)
```

### 6.3 데이터베이스 쿼리 최적화

```python
# ❌ Bad: N+1 문제
for todo in todos:
    user = db.query(User).filter(User.id == todo.user_id).first()
    print(f"{todo.title} by {user.name}")


# ✅ Good: JOIN 사용
todos_with_users = (
    db.query(Todo, User)
    .join(User, Todo.user_id == User.id)
    .all()
)
for todo, user in todos_with_users:
    print(f"{todo.title} by {user.name}")
```

### 8.2 CI/CD 통합

```yaml
# .github/workflows/quality.yml
name: Code Quality

on: [push, pull_request]

jobs:
  quality:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v2
      - name: Set up Python
        uses: actions/setup-python@v2
        with:
          python-version: '3.11'

      - name: Install dependencies
        run: |
          pip install black isort flake8 mypy bandit pytest pytest-cov

      - name: Black
        run: black . --check --line-length 100

      - name: isort
        run: isort . --check --profile black

      - name: Flake8
        run: flake8 . --max-line-length=100

      - name: Mypy
        run: mypy . --ignore-missing-imports

      - name: Bandit
        run: bandit -r . -ll

      - name: Tests
        run: pytest tests/ --cov=. --cov-fail-under=80
```
