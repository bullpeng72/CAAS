## 시스템 개요

CAAS는 자연어 요구사항을 입력받아 **CrewAI 기반 멀티에이전트 시스템** 또는 **FastAPI CRUD 백엔드**를 자동으로 설계하고 생성하는 **프레임워크 중심 플랫폼**입니다.

### 핵심 특징

- **Framework-First 아키텍처**: CLI, SDK, Python API를 통한 접근
- **이중 코드 생성 전략**:
  - **AGENT_BASED**: CrewAI 멀티에이전트 시스템 (CONTENT_GENERATION, RESEARCH, CHATBOT 등)
  - **CRUD_BASED**: FastAPI + SQLAlchemy 백엔드 (TASK_MANAGEMENT, USER_MANAGEMENT 등)
- **BMAD 6-Phase 방법론**: Business → Multi-agent → Architecture → Design → Development → Quality Assurance
- **Expert Agent Collaboration**: 5명의 전문가 에이전트 협업
- **도메인 기반 분류**: 17개 도메인 자동 분류 및 최적 전략 선택
- **온톨로지 기반 추론**: 도메인 지식을 활용한 지능적 역할/도구 매핑
- **이중 그래프 백엔드**: Neo4j (프로덕션) 또는 임베디드 (개발)
- **템플릿 + LLM 하이브리드 생성**: Jinja2 템플릿 + LLM 기반 코드 생성
- **개발 산출물 자동 생성**: 8가지 타입의 개발 문서 자동 생성
- **보안 우선 설계**: Path Traversal, YAML Bomb, Injection 방어

### 프로덕션 규모

- **코드량**: 27,840+ 라인 (caas_framework/)
- **파일 수**: 200+ Python 파일
- **CLI 명령**: 20개 메인 명령 + 19개 서브명령 = 39개 작업
- **도구 지원**: 40+ CrewAI 도구
- **Validator**: 6개 타입
- **산출물**: 8가지 자동 문서

**BMAD 6-Phase 프로세스**:

```python
# Phase 1: Concretization
golden_data = await concretizer.concretize(requirement)

# Phase 2: Discovery
domain_info = await discovery_engine.analyze(golden_data)

# Phase 3: Architecture
traceability_matrix = build_traceability(golden_data, agents, tasks)

# Phase 4: Design
completeness_report = validate_completeness(agents, tasks, golden_data)
if completeness < threshold:
    # Gap Filling
    filled_code = await gap_filler.fill_gaps(missing_features)

# Phase 5: Development
code = await code_generator.generate(agents, tasks)

# Phase 6: Quality Assurance
validation_result = await validator.validate(code)
```

#### 1.2 Code Generation (`codegen/`)

  - Layer 2: Fallback (템플릿 기반 대체)

- `deployment_generator.py` - 배포 설정

- `frontend_generator.py` - Frontend 코드
- `production_generator.py` - 프로덕션 코드
- `test_generator.py` - 테스트 코드
- `domain_strategy.py` - 도메인별 전략
- `execution_validator.py` - 실행 검증
- `injectors.py` - 의존성 주입
- `port_manager.py` - 포트 관리

```python
class LLMPlugin(ABC):
```

```python
class AgentFactory:
```

```python
class CodeGenerationStrategy(ABC):

        pass

class AgentBasedStrategy(CodeGenerationStrategy):
```

### 4. Observer Pattern

**Progress Reporting**:
```python
class ProgressReporter:
    def __init__(self):
        self.observers = []

    def notify(self, event):
        for observer in self.observers:
            observer.update(event)
```

### 5. Template Method Pattern

**BMAD Engine**:
```python
class BMADEngine:
    async def run(self, requirement):
        # Template method
        golden_data = await self.concretize(requirement)
        domain_info = await self.discover(golden_data)
        architecture = await self.design_architecture(golden_data)
        agents, tasks = await self.design(golden_data)
        code = await self.develop(agents, tasks)
        report = await self.assure_quality(code)
        return report
```
