### 🎓 전문가용
**[전문가 방법론 가이드](./전문가_방법론_가이드.md)**

- **대상**: 대규모 프로젝트를 구축하는 전문 개발자
- **학습 시간**: 2-3시간 (실습 포함)
- **내용**:
  - **방법론 이론**: BMAD, Spec-Driven, TDD
  - **BMAD 6-Phase 심화**: Phase별 상세 분석
  - **대규모 프로젝트 전략**:
    - 단계적 접근 (Incremental)
    - 반복적 정제 (Iterative)
    - 모듈화 접근 (Modular)
  - **실전 E-Commerce 플랫폼 구축**:
    - 58개 기능, 12개 에이전트
    - 완전한 워크플로우 (요구사항 → 배포)
    - 검증 및 최적화
  - **고급 기능 활용**:
    - Session Management
    - Workflow Management
    - Plugin System
    - Artifact Generation
    - Component-Level Generation
  - **최적화 및 튜닝**:
    - 성능 최적화
    - 비용 최적화
    - 품질 향상

**추천 대상**:
- ✅ CAAS 기본 사용법 숙지
- ✅ 대규모 시스템 구축 경험
- ✅ 프로덕션 배포 계획
- ✅ BMAD 방법론 이해 필요
- ✅ 모든 고급 기능 활용

## 💡 핵심 개념

### BMAD 방법론
```
Phase 0: Concretization   → Golden Data 생성
Phase 1: Discovery        → 요구사항 분석
Phase 2: Architecture     → 시스템 설계 + Traceability
Phase 3: Design           → Agent/Task 설계 + Completeness
Phase 4: Development      → 스펙 생성
Phase 5: Delivery         → 코드 생성 + 배포
```

### 최적 사용 사례 (95%+ 구현률)
1. **CrewAI 멀티 에이전트 시스템** (98.7%)
2. **데이터 분석 파이프라인** (98.3%)
3. **AI 자동화 워크플로우**
4. **콘텐츠 생성 시스템**

### 제한 사항
- ⚠️ 웹 프레임워크 직접 생성 (Flask/FastAPI)
- ⚠️ Frontend UI 코드 (HTML/CSS/JavaScript)
- ℹ️ 대신 비즈니스 로직 처리 에이전트 생성

## ❓ FAQ

### Q: 어떤 가이드부터 읽어야 하나요?

**A**: CAAS가 처음이라면 **초보자 가이드**부터 시작하세요. 기본 사용법을 익힌 후 **전문가 가이드**로 넘어가는 것을 추천합니다.

### Q: 대규모 프로젝트를 만들고 싶은데 어디서 시작하나요?

**A**: **전문가 방법론 가이드**의 "실전: E-Commerce 플랫폼 구축" 섹션을 따라하세요. 58개 기능, 12개 에이전트를 가진 완전한 시스템을 단계별로 구축할 수 있습니다.

### Q: BMAD 방법론이 무엇인가요?

**A**: Build-Measure-Analyze-Deploy의 약자로, CAAS의 핵심 워크플로우입니다. **전문가 가이드**의 "방법론 이론" 섹션에서 상세히 설명합니다.

### Q: 생성된 코드를 어떻게 커스터마이징하나요?

**A**: **전문가 가이드**의 "고급 팁 & 트릭" 섹션에서 컴포넌트 재생성, 커스텀 도구 추가 등의 방법을 설명합니다.
