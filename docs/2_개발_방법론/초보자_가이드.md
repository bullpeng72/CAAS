## 📖 이 가이드에 대하여

이 가이드는 CAAS를 처음 접하는 분들을 위한 **실전 중심** 튜토리얼입니다. 복잡한 이론보다는 **바로 실행 가능한 예제**를 통해 CAAS의 핵심 기능을 배울 수 있습니다.

- ✅ CrewAI 멀티 에이전트 시스템 만들기 (10분)

### 학습 시간
- **빠른 시작**: 10분
- **전체 완료**: 30-45분

## 🎯 레벨 2: 데이터 분석 에이전트 (15분)

### 실전 예제: CSV 데이터 분석 시스템

이번에는 **더 구체적인 요구사항**을 작성해봅니다.

```bash
caas generate "CSV 파일을 읽고, 통계 분석(평균, 중앙값, 표준편차)을 수행하고, 그래프를 생성하는 데이터 분석 에이전트 시스템" \
  --domain DATA_ANALYSIS \
  --output ./data-analyzer \
  --verbosity verbose
```

**주요 옵션 설명**:
- `--domain DATA_ANALYSIS`: 도메인을 명시하여 더 정확한 코드 생성
- `--verbosity verbose`: 상세한 진행 상황 표시

### 결과 확인

```bash
cd data-analyzer

# 생성된 에이전트 확인
cat agents.py
```

**agents.py 내용 예시**:
```python
from crewai import Agent

def create_agents():
    agents = {}

    # CSV 데이터 수집 에이전트
    agents["data_ingestion_agent"] = Agent(
        role="CSV 데이터 수집 에이전트",
        goal="CSV 파일을 읽고 유효성을 검사한다",
        backstory="데이터 수집 전문가",
        verbose=True,
        allow_delegation=True,
        tools=["file_read", "file_write"]
    )

    # 통계 분석 에이전트
    agents["statistical_analysis_agent"] = Agent(
        role="통계 분석 에이전트",
        goal="데이터에 대한 통계 분석을 수행한다",
        backstory="통계학 전문가",
        verbose=True,
        allow_delegation=True,
        tools=["file_read", "file_write"]
    )

    return agents
```

## 🎯 레벨 3: 뉴스 요약 AI 시스템 (20분)

### 멀티 에이전트 협업 시스템

```bash
caas generate "뉴스 기사를 수집하고, 요약하고, 카테고리별로 분류하는 AI 뉴스 큐레이션 시스템. 웹 검색으로 최신 뉴스를 수집하고, 각 기사를 3-5문장으로 요약하며, 정치/경제/기술/스포츠로 분류한다." \
  --domain CONTENT_CREATION \
  --output ./news-curator \
  --verbosity verbose
```

### 고급 기능: 요구사항 정제

생성 전에 요구사항을 더욱 명확하게 만들 수 있습니다.

```bash
# 1. 갭 분석
caas analyze-gaps "뉴스 큐레이션 시스템" \
  --output gaps.json

# 2. 대화형 질문으로 요구사항 명확화
caas questions --gaps gaps.json --domain CONTENT_CREATION

# 3. 요구사항 자동 확장
caas expand "뉴스 큐레이션 시스템" \
  --gaps gaps.json \
  --output expanded_requirements.json

# 4. 확장된 요구사항으로 재생성
caas generate "뉴스 큐레이션 시스템" \
  --golden-data expanded_requirements.json \
  --output ./news-curator-v2
```

### 생성된 시스템 확인

```bash

# role="요약 에이전트"

```

## 🔧 유용한 CLI 명령어

### 프로젝트 관리

```bash
# 생성된 프로젝트 목록 조회
caas list

# 프로젝트 상태 확인
caas status <project-id>

# 프로젝트 다운로드
caas download <project-id> ./my-project
```

### 검증 및 수정

```bash
# 코드 검증
caas validate --validator all \
  --agents ./agents.json \
  --tasks ./tasks.json \
  --golden-data ./golden_data.json

# 자동 수정
caas fix \
  --agents ./agents.json \
  --tasks ./tasks.json \
  --golden-data ./golden_data.json \
  --level 3
```

### 컴포넌트 재생성

특정 부분만 다시 생성하고 싶을 때:

```bash
# tests만 재생성
caas codegen --component tests \
  --agents ./agents.json \
  --tasks ./tasks.json

# tools.py만 재생성
caas codegen --component tools \
  --agents ./agents.json \
  --tasks ./tasks.json
```

## ❓ 자주 묻는 질문 (FAQ)

### Q1: Phase가 중간에 멈춥니다

**A**: 대부분 API 키 또는 네트워크 문제입니다.

```bash
# API 키 확인
cat .env | grep API_KEY

# 로그 확인
caas generate "..." --verbosity debug
```

### Q2: 생성된 코드가 실행되지 않습니다

**A**: 의존성 설치를 확인하세요.

```bash
# 가상 환경 생성 (권장)
python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate

# 의존성 설치
pip install -r requirements.txt

# Python 버전 확인 (3.11+ 필요)
python --version
```

### Q3: 에이전트가 0개 생성됩니다

**A**: 요구사항을 더 구체적으로 작성하세요.

```bash
# ❌ 나쁜 예
caas generate "앱 만들기"

# ✅ 좋은 예
caas generate "사용자 인증, 게시글 작성, 댓글 기능이 있는 블로그 앱을 관리하는 AI 에이전트 시스템"
```

### Q4: 구현률이 낮습니다

**A**: CAAS는 **CrewAI 에이전트 생성**에 최적화되어 있습니다.

```bash
# ❌ 제한적인 지원 (구현률 2-50%)
caas generate "Flask 웹 애플리케이션"
caas generate "React 프론트엔드"

# ✅ 최적 사용 (구현률 95%+)
caas generate "블로그 관리 AI 에이전트 시스템"
caas generate "데이터 분석 파이프라인"
caas generate "고객 문의 자동 응답 에이전트"
```
