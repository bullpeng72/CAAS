## ❓ 문제 진단 트리

### 문제 1: Phase가 중간에 멈춤

**증상**: Phase 진행 중 멈추거나 에러 발생

**진단 프로세스**:

```
Phase 멈춤
    │
    ├─→ API 키 문제?
    │   ├─→ cat .env | grep API_KEY
    │   ├─→ API 키가 없거나 잘못됨
    │   └─→ 해결: .env 파일에 올바른 API 키 입력
    │
    ├─→ 네트워크 문제?
    │   ├─→ ping api.openai.com
    │   ├─→ 연결 불가
    │   └─→ 해결: 인터넷 연결 확인, 방화벽 설정 확인
    │
    ├─→ API 할당량 초과?
    │   ├─→ 에러 메시지에 "quota" 또는 "rate limit" 포함
    │   └─→ 해결: API 키 플랜 확인, 잠시 후 재시도
    │
    └─→ 디버그 모드 실행
        └─→ caas generate "..." --verbosity debug
            └─→ 로그에서 정확한 에러 확인
```

**해결책**:

```bash
# 1. API 키 확인
cat .env | grep API_KEY
# 없거나 잘못됨 → 올바른 키 입력

# 2. 로그 확인
caas generate "할일 관리 에이전트" \
  --output ./todo-agent \
  --verbosity debug 2>&1 | tee debug.log

# 3. 특정 Phase만 재실행 (Phase 2부터 재개)
caas generate-phase --phase 2 \
  --golden-data ./todo-agent/artifacts/golden_data.json \
  --output ./todo-agent
```

### 문제 2: 생성된 코드가 실행되지 않음

**증상**: `python main.py` 실행 시 에러 발생

**진단 프로세스**:

```
실행 에러
    │
    ├─→ NameError: name 'file_read' is not defined? ⭐ 가장 흔함!
    │   ├─→ python -c "from agents import create_agents"
    │   ├─→ NameError 발생
    │   └─→ 해결: sed -i 's/tools=\[.*\]/tools=[]/' agents.py
    │
    ├─→ ModuleNotFoundError?
    │   ├─→ pip list | grep crewai
    │   ├─→ crewai 없음
    │   └─→ 해결: pip install -r requirements.txt
    │
    ├─→ ImportError (순환 참조)?
    │   ├─→ python -c "import agents"
    │   ├─→ 에러 발생
    │   └─→ 해결: caas fix --level 3 실행
    │
    ├─→ API 키 미설정?
    │   ├─→ 에러 메시지: "API key not found"
    │   └─→ 해결: .env 파일 확인 및 설정
    │
    └─→ Python 버전 문제?
        ├─→ python --version
        ├─→ 3.10 이하
        └─→ 해결: Python 3.11+ 설치
```

**해결책**:

```bash
# ⭐ 가장 먼저 시도: NameError 수정 (v1.0.0 필수!)
sed -i 's/tools=\[.*\]/tools=[]/' agents.py

# 수정 확인
python -c "from agents import create_agents; agents = create_agents()"
# 에러 없으면 ✅ 성공

# 여전히 에러 발생 시:

# 1. 의존성 재설치 (가상 환경에서)
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt

# 2. 자동 수정 실행
caas fix \
  --agents ./agents.json \
  --tasks ./tasks.json \
  --golden-data ./golden_data.json \
  --level 3 \
  --output ./

# 3. 검증
caas validate --validator all \
  --agents ./agents.json \
  --tasks ./tasks.json \
  --golden-data ./golden_data.json

# 4. 재실행
python main.py
```

**v1.0.0 알려진 이슈**:

- 모든 프로젝트에서 agents.py 수정이 필요합니다

from crewai import Agent
from typing import Dict

def create_agents() -> Dict[str, Agent]:
    """Create all agents for data analysis system."""
    agents = {}

    # CSV 데이터 수집 에이전트
    agents["data_ingestion_agent"] = Agent(
        role="CSV Data Ingestion Specialist",
        goal="Read and parse CSV files with high accuracy and efficiency",
        backstory="You are an expert in data ingestion with 10+ years of experience "
                  "handling various data formats. You ensure data quality from the source.",
        verbose=True,
        allow_delegation=True,
        tools=["file_read_tool", "csv_parser_tool"]
    )

    # 통계 분석 에이전트
    agents["analysis_agent"] = Agent(
        role="Statistical Analysis Expert",
        goal="Perform accurate statistical analysis on datasets",
        backstory="You are a statistician with expertise in descriptive and "
                  "inferential statistics. You provide insights through rigorous analysis.",
        verbose=True,
        allow_delegation=True,
        tools=["numpy_calculator", "scipy_stats"]
    )

    # 시각화 에이전트
    agents["visualization_agent"] = Agent(
        role="Data Visualization Specialist",
        goal="Create clear and insightful data visualizations",
        backstory="You are a data visualization expert who transforms complex "
                  "data into understandable visual stories.",
        verbose=True,
        allow_delegation=False,
        tools=["matplotlib_tool", "seaborn_tool"]
    )

    return agents
