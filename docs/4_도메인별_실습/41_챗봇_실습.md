## 1. 프로젝트 생성 (5분)

### 요구사항
```
고객 지원 챗봇을 만들어줘.
FAQ 검색, 제품 추천, 문의 처리, 대화 컨텍스트 관리 기능이 필요해.
```

### 실행
```bash
caas generate "고객 지원 챗봇. FAQ 검색, 제품 추천, 문의 처리, 대화 컨텍스트 관리" \
  --domain conversational_ai \
  --output ./chatbot-system \
  --enable-frontend \
  --frontend-framework streamlit
```

> **참고**: `--enable-frontend` 플래그는 선택적입니다. CAAS는 요구사항에서 "챗봇", "UI", "대화" 등의 키워드를 자동으로 감지하여 프론트엔드를 생성합니다.

## 5. 커스터마이징 (선택)

### UI 개선 (Streamlit)
```python
# app.py 수정
import streamlit as st

st.title("💬 고객 지원 챗봇")

# 사이드바에 설정 추가
with st.sidebar:
    st.subheader("설정")
    tone = st.selectbox("응답 톤", ["친절", "전문적", "캐주얼"])
    language = st.selectbox("언어", ["한국어", "영어"])

    st.subheader("통계")
    st.metric("오늘 대화", "47")
    st.metric("평균 만족도", "4.2/5.0")

# 채팅 인터페이스
if "messages" not in st.session_state:
    st.session_state.messages = []

for message in st.session_state.messages:
    with st.chat_message(message["role"]):
        st.markdown(message["content"])
        if "sentiment" in message:
            st.caption(f"감정: {message['sentiment']}")

# 사용자 입력
if prompt := st.chat_input("무엇을 도와드릴까요?"):
    # CrewAI 실행
    result = crew.kickoff(inputs={"user_message": prompt, "tone": tone})

    st.session_state.messages.append({
        "role": "user",
        "content": prompt
    })
    st.session_state.messages.append({
        "role": "assistant",
        "content": result.output,
        "sentiment": result.sentiment
    })
    st.rerun()
```
