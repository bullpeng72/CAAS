## CLI로 빠른 시작

### 🔷 첫 프로젝트 생성

CLI는 `caas_framework`를 직접 사용 - API 서버 불필요.

**첫 프로젝트 생성:**
```bash
# 기본 생성
caas generate "사용자 인증 기능이 있는 할일 관리 시스템 만들기"

# 옵션 포함
caas generate "블로그 플랫폼 만들기" \
  --domain CONTENT_CREATION \
  --output ./my-blog \
  --deployment kubernetes

# Phase 1-3 기능 포함
caas generate "REST API 서버 만들기" \
  --gap-filling            # 자동 갭 채우기 활성화
  --no-traceability        # Phase 2 추적성 비활성화
  --no-completeness        # Phase 3 완전성 검증 비활성화
```

### 🔷 옵션 2: Python API (프로그래밍 방식)

**Python 코드로 직접 사용:**

```python
from caas_framework.bmad.engine import BMADEngine
from caas_framework.plugins.llm.openai_plugin import OpenAIPlugin
import asyncio

async def main():
    # LLM 플러그인 초기화
    llm = OpenAIPlugin(model="gpt-4o-mini")

    # BMAD 엔진 생성
    engine = BMADEngine(llm_plugin=llm)

    # 프로젝트 생성
    result = await engine.run(
        requirement="할일 관리 시스템 만들기",
        domain="TASK_MANAGEMENT",
        output_dir="./generated"
    )

    # 결과 확인
    print(f"✅ Generated {len(result.files)} files")
    print(f"Completeness Score: {result.completeness_score}/100")
    print(f"Implementation Rate: {result.implementation_rate:.1f}%")

asyncio.run(main())
```

**진행률 추적 예제:**

```python
from caas_framework.bmad.engine import BMADEngine
from caas_framework.plugins.llm.openai_plugin import OpenAIPlugin
from caas_framework.reporting.progress_reporter import ProgressReporter, VerbosityLevel
import asyncio

async def main():
    # LLM 플러그인 초기화
    llm = OpenAIPlugin(model="gpt-4o-mini")

    # Progress Reporter 설정
    reporter = ProgressReporter(verbosity=VerbosityLevel.VERBOSE)

    # BMAD 엔진 생성
    engine = BMADEngine(
        llm_plugin=llm,
        progress_reporter=reporter
    )

    # 실행 (실시간 진행률 표시)
    result = await engine.run(
        requirement="블로그 플랫폼 만들기",
        domain="CONTENT_CREATION"
    )

    # 결과 요약
    print("\n" + "="*60)
    print(f"✓ Done! Files saved to: {result.output_dir}")
    print(f"✓ Completeness: {result.completeness_score}/100")
    print(f"✓ Implementation Rate: {result.implementation_rate:.1f}%")

asyncio.run(main())
```

**Phase별 실행 예제:**

```python
from caas_framework.bmad.engine import BMADEngine
from caas_framework.plugins.llm.openai_plugin import OpenAIPlugin
import asyncio

async def main():
    llm = OpenAIPlugin(model="gpt-4o-mini")
    engine = BMADEngine(llm_plugin=llm)

    # Phase 1-2만 실행 (요구사항 분석만)
    result = await engine.run_phase(
        requirement="전자상거래 플랫폼 만들기",
        phases=[1, 2],  # Concretization + Discovery
        output_dir="./analysis"
    )

    print(f"Golden Data: {result.golden_data}")
    print(f"Domain: {result.domain}")
    print(f"Features: {len(result.features)}")

asyncio.run(main())
```

**참고**: CAAS는 **Framework-First 아키텍처**입니다. 별도의 REST API 서버나 UI 애플리케이션은 제공하지 않으며, CLI 또는 Python API를 직접 사용합니다.

## 🔥 Phase 1-3 기능 (v1.0.0+)

CAAS v1.0.0은 더 나은 코드 생성을 위한 향상된 기능을 도입합니다:

### Phase 1-3란?

- **Phase 1**: 계층적 기능 추출 - 요구사항에서 2-4배 더 많은 기능 추출
- **Phase 2**: 추적성 매트릭스 - 기능 → 태스크 → 코드 추적 (100% 커버리지)
- **Phase 3**: 완전성 검증 - AST + LLM으로 구현 완전성 검증

### Phase 1-3 사용하기

**CLI:**
```bash
# 모두 활성화 (기본값)
caas generate "REST API 만들기"

# 선택적 제어
caas generate "REST API 만들기" \
  --no-traceability        # Phase 2 건너뛰기
  --no-completeness        # Phase 3 건너뛰기
  --gap-filling            # 자동 갭 채우기 활성화
```

**Python SDK:**
```python
result = await client.generate(
    requirement="REST API 만들기",
    config={
        "enable_traceability": True,
        "enable_completeness_validation": True,
        "enable_gap_filling": False
    }
)
```

### Phase 결과

**Phase 1 출력**: `features_hierarchical.json`
```json
{
  "feature_areas": [
    {
      "name": "인증",
      "features": ["사용자 로그인", "비밀번호 재설정", "토큰 관리"]
    },
    {
      "name": "할일 관리",
      "features": ["할일 생성", "할일 수정", "할일 삭제", "할일 목록"]
    }
  ],
  "total_features": 7,
  "improvement_over_baseline": "220%"
}
```

**Phase 2 출력**: `traceability_matrix.json`
```json
{
  "features": {
    "F001_사용자_로그인": {
      "tasks": ["T001_사용자_인증", "T002_토큰_생성"],
      "code_files": ["app/auth.py", "app/models.py"],
      "coverage": "100%"
    }
  }
}
```

**Phase 3 출력**: `completeness_report.json`
```json
{
  "overall_score": 87.5,
  "feature_implementation": {
    "fully_implemented": 10,
    "partially_implemented": 2,
    "not_implemented": 0
  },
  "recommendations": [
    "app/auth.py의 login()에 에러 처리 추가",
    "API 엔드포인트에 rate limiting 구현"
  ]
}
```

## 🐛 일반적인 문제

### CLI: "caas: command not found"

**해결책:**
```bash
pip install -e ".[cli]"
```

### API: "Connection refused"

**해결책:**
```bash
# API 서버가 실행 중인지 확인
python -m app.api
```

### 생성: "OPENAI_API_KEY not set"

**해결책:**
```bash
# .env 파일이 존재하고 API 키가 있는지 확인
cat .env | grep OPENAI_API_KEY

# 또는 터미널에서 설정
export OPENAI_API_KEY=sk-your-key
```

### 4. SDK로 동시 생성

```python
# 여러 프로젝트를 병렬로 생성
async def generate_batch():
    async with AsyncCAAS() as client:
        tasks = [
            client.generate("할일 앱"),
            client.generate("블로그 플랫폼"),
            client.generate("채팅 시스템")
        ]
        results = await asyncio.gather(*tasks)
        return results
```
