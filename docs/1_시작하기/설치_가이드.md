# CAAS 설치 가이드

CAAS (CrewAI Agent Auto-generation System) 완전 설치 가이드입니다.

---

## 시스템 요구사항

- **Python**: 3.11 이상
- **Git**: 리포지토리 클론용
- **API 키**: OpenAI API 키 또는 Anthropic API 키 (최소 하나 필수)
- **선택사항**: Neo4j (지식 그래프 시각화용)

---

## 설치 방법

### 방법 1: 개발 설치 (권장)

개발 목적이거나 소스 코드를 수정하려는 경우 권장합니다.

#### 1단계: 리포지토리 클론

```bash
git clone https://github.com/aidx/caas.git
cd caas
```

#### 2단계: 가상 환경 생성

```bash
# 가상 환경 생성
python3 -m venv venv

# 활성화 (Linux/macOS)
source venv/bin/activate

# 활성화 (Windows)
venv\Scripts\activate
```

#### 3단계: CAAS 프레임워크 설치

프레임워크는 `pyproject.toml`을 사용하여 선택적 의존성과 함께 설치됩니다.

**기본 설치 (프레임워크 + CLI):**
```bash
pip install -e .
```

> 💡 **참고**: 기본 설치에 CLI가 포함됩니다. CAAS는 CLI 기반 도구로 설계되었으며, 별도의 UI나 API 서버는 포함하지 않습니다.

**개발용 (테스트 도구 포함):**
```bash
pip install -e ".[dev]"
```

#### 4단계: 환경 변수 설정

예제 환경 파일을 복사합니다:
```bash
cp .env.example .env
```

`.env` 파일을 편집하여 API 키를 추가합니다:
```env
# 필수: 최소 하나의 LLM 제공자
OPENAI_API_KEY=sk-your-openai-key-here
ANTHROPIC_API_KEY=sk-ant-your-anthropic-key-here

# 선택: Neo4j 지식 그래프용
NEO4J_URI=bolt://localhost:7687
NEO4J_USER=neo4j
NEO4J_PASSWORD=password

# 선택: API 서버 설정
API_URL=http://localhost:8000
```

#### 5단계: 설치 확인

```bash
# 프레임워크 설치 확인
python -c "import caas_framework; print(f'CAAS Framework v{caas_framework.__version__}')"

# CLI 확인
caas --help

# 프레임워크 기능 확인
python -c "from caas_framework import CrewAIFramework; print('✓ Framework ready')"
```

---

### 방법 2: 프로덕션 설치 (PyPI)

**참고**: PyPI 패키지는 아직 게시되지 않았습니다. 현재는 개발 설치를 사용하세요.

게시 후:
```bash
# 프레임워크만
pip install caas-framework

# CLI 포함
pip install caas-framework[cli]

# Streamlit UI 포함
pip install caas-framework[streamlit]

# 전체
pip install caas-framework[all]
```

## CAAS 실행하기

CAAS는 여러 인터페이스를 제공합니다. 필요에 따라 선택하세요:

### 옵션 1: CLI (명령줄 인터페이스)

**설치:**
```bash
pip install -e ".[cli]"
```

**사용:**
```bash
# 프로젝트 생성
caas generate "할일 관리 시스템 만들기"

# 상태 확인
caas status

# 프로젝트 목록
caas list
```

**중요**: CLI는 `caas_framework`를 직접 사용하며 FastAPI 서버 실행이 **필요하지 않습니다**.

---

> 💡 **참고**: CAAS는 CLI 기반 도구로, 별도의 웹 UI나 API 서버를 포함하지 않습니다. 생성된 프로젝트에는 필요에 따라 Streamlit UI나 FastAPI 백엔드가 포함될 수 있습니다.

## 선택적 구성요소

### Neo4j (지식 그래프)

지식 그래프 시각화 및 패턴 저장용:

**Docker 사용:**
```bash
docker run -d \
  --name neo4j \
  -p 7474:7474 -p 7687:7687 \
  -e NEO4J_AUTH=neo4j/password \
  neo4j:latest
```

**접속**: http://localhost:7474

**.env에서 설정:**
```env
NEO4J_URI=bolt://localhost:7687
NEO4J_USER=neo4j
NEO4J_PASSWORD=password
```

### Redis (선택 - 다중 서버 설정)

분산 배포 시에만 필요:

```bash
docker run -d --name redis -p 6379:6379 redis:latest
```

## 검증 단계

### 1. 프레임워크 import 테스트

```bash
python -c "from caas_framework import CrewAIFramework; print('✓ Framework imported successfully')"
```

### 2. CLI 테스트 (설치한 경우)

```bash
caas --version
caas --help
```

### 3. 생성 테스트 (빠른 테스트)

`test_generation.py` 생성:
```python
import asyncio
from caas_framework import CrewAIFramework

async def test():
    framework = CrewAIFramework(llm_provider="openai")
    await framework.initialize()

    result = await framework.generate_from_requirement(
        requirement="간단한 할일 앱 만들기",
        domain="TASK_MANAGEMENT"
    )

    print(f"✓ Generation {'successful' if result.success else 'failed'}")
    print(f"  Agents: {len(result.agent_specs)}")
    print(f"  Tasks: {len(result.task_specs)}")

    await framework.close()

asyncio.run(test())
```

실행:
```bash
python test_generation.py
```

## 문제 해결

### 문제: ModuleNotFoundError: No module named 'caas_framework'

**해결책:**
```bash
# 개발 모드로 재설치
cd /path/to/caas
pip install -e . --force-reinstall
```

---

### 문제: "OPENAI_API_KEY not found"

**해결책:**
1. 프로젝트 루트에 `.env` 파일이 있는지 확인
2. API 키 설정 확인: `cat .env | grep OPENAI_API_KEY`
3. 터미널/셸을 재시작하여 환경 다시 로드

---

### 문제: SDK 사용 시 "Connection refused"

**해결책:**
- SDK는 FastAPI 서버 실행 필요
- 서버 시작: `python -m app.api`
- 서버 실행 확인: `curl http://localhost:8000/health`

---

### 문제: CLI 명령을 찾을 수 없음

**해결책:**
```bash
# CLI 의존성 재설치
pip install -e ".[cli]"

# entry point 등록 확인
which caas
```

---

### 문제: Streamlit import 오류

**해결책:**
```bash
# Streamlit 의존성 설치
pip install -e ".[streamlit]"
```

---

### 문제: "Port 8000 already in use"

**해결책:**
```bash
# 옵션 1: 포트 8000을 사용하는 프로세스 종료
lsof -ti:8000 | xargs kill -9

# 옵션 2: 다른 포트 사용
uvicorn app.api:app --port 8001
```

---

### 문제: Neo4j 연결 실패

**참고**: Neo4j는 선택사항입니다. 없어도 프레임워크는 동작합니다.

**해결:**
1. Neo4j 실행 확인: `docker ps | grep neo4j`
2. 연결 테스트: `cypher-shell -u neo4j -p password`
3. `.env`의 인증 정보 확인

## 아키텍처 개요

CAAS는 모듈식 아키텍처를 가지고 있습니다:

```
caas_framework/     - 핵심 프레임워크 (UI 독립적)
    ├── agents/     - 5개 전문 에이전트
    ├── bmad/       - BMAD 6단계 엔진
    ├── codegen/    - 코드 생성
    ├── knowledge/  - 온톨로지 & 지식 그래프
    └── ...

app/                - FastAPI 백엔드 (선택)
caas_cli/           - CLI 인터페이스 (선택)
caas_streamlit/     - Streamlit UI (선택)
caas_sdk/           - Python SDK (선택)
vscode-extension/   - VS Code 확장 (선택)
```

**핵심 설계**:
- `caas_framework`가 핵심 - 독립적으로 완전히 기능
- 모든 UI (CLI, Streamlit, API)는 선택사항이며 별도 설치 가능
- CLI는 프레임워크를 직접 사용 (API 서버 불필요)
- SDK/VS Code 확장은 API 서버 필요

## 설치 결정 트리

**사용 사례별 설치 선택:**

| 사용 사례 | 설치 명령 | 구성요소 |
|----------|----------|---------|
| **터미널에서 코드 생성** | `pip install -e ".[cli]"` | Framework + CLI |
| **웹 인터페이스 사용** | `pip install -e ".[streamlit]"` | Framework + Streamlit |
| **Python SDK로 개발** | `pip install -e ".[all]"` + API 서버 실행 | Framework + API + SDK |
| **VS Code 통합** | `pip install -e ".[all]"` + API 서버 실행 | Framework + API + Extension |
| **개발** | `pip install -e ".[dev]"` | 모든 것 + 테스트 도구 |
| **풀스택** | `pip install -e ".[all]"` | 모든 인터페이스 |
