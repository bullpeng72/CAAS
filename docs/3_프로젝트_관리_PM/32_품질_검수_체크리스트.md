## Phase 0: Golden Data 검수

### 필수 항목

| 항목 | 기준 | 명령어 | 합격 기준 |
|------|------|--------|----------|
| Features 개수 | ≥3 | `jq '.features\|length' golden_data.json` | 3 이상 |
| Entities 개수 | ≥1 | `jq '.entities\|length' golden_data.json` | 1 이상 |
| Description 완전성 | 100% | `jq '.features[]\|select(.description==null)' golden_data.json` | 빈 출력 |
| Priority 정의 | 100% | `jq '.features[]\|select(.priority==null)' golden_data.json` | 빈 출력 |

### 검수 스크립트

```bash
#!/bin/bash
# phase0_check.sh

echo "=== Phase 0 Quality Check ==="

FEATURES=$(jq '.features|length' golden_data.json)
ENTITIES=$(jq '.entities|length' golden_data.json)
NO_DESC=$(jq '[.features[]|select(.description==null)]|length' golden_data.json)
NO_PRIORITY=$(jq '[.features[]|select(.priority==null)]|length' golden_data.json)

echo "Features: $FEATURES (기준: ≥3)"
echo "Entities: $ENTITIES (기준: ≥1)"
echo "Description 누락: $NO_DESC (기준: 0)"
echo "Priority 누락: $NO_PRIORITY (기준: 0)"

if [ $FEATURES -ge 3 ] && [ $ENTITIES -ge 1 ] && [ $NO_DESC -eq 0 ] && [ $NO_PRIORITY -eq 0 ]; then
    echo "✅ PASS"
    exit 0
else
    echo "❌ FAIL"
    exit 1
fi
```

## Phase 2: Architecture 검수 ⭐ Critical

```bash
  --golden-data ./project/golden_data.json \
```

**불합격 예시**:

- [ ] **Traceability: 100%** (필수)
- [ ] Architecture pattern 정의됨
- [ ] Database 스키마 존재
- [ ] Tools 3개 이상 설계됨

## Phase 5: 코드 검수 ⭐ 최종 관문

### 필수 항목

| 항목 | 기준 | 명령어 | 합격 기준 |
|------|------|--------|----------|
| 파일 개수 | 8개 | `ls -1\|wc -l` | 8 |
| 구문 오류 | 0개 | `python -m py_compile *.py` | Exit 0 |
| Code Quality | >8.5 | `caas validate --validator code-quality` | 8.5-10.0 |
| Security (Critical) | 0개 | `caas qa security-scan --owasp` | 0 Critical |
| Test Coverage | >80% | `pytest --cov --cov-fail-under=80` | ≥80% |
