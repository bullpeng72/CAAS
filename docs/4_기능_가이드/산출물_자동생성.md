# 산출물 자동 생성 (Artifact Generation)

## 개요

CAAS는 개발 과정에서 자동으로 산출물(문서)을 생성하는 기능을 제공합니다. 이를 통해 각 단계의 품질을 확인하고, 프로젝트 문서화를 자동화할 수 있습니다.

## 지원하는 산출물 타입

### 1. 프로젝트 기획서 (Project Proposal)
- **단계**: 요구사항 입력 후
- **내용**: 프로젝트 배경, 목적, 범위, 기대 효과, 일정
- **템플릿**: `project_proposal.md.j2`

### 2. 요구사항 명세서 (Requirements Specification)
- **단계**: Golden Data 생성 후
- **내용**: 기능/비기능 요구사항, 사용자 스토리, 제약사항
- **템플릿**: `requirements_spec.md.j2`

### 3. 아키텍처 설계서 (Architecture Design)
- **단계**: BMAD 매핑 후
- **내용**: 시스템 구조, 컴포넌트 설계, 통신 흐름
- **템플릿**: `architecture_design.md.j2` (예정)

### 4. 데이터 설계서 (Data Design)
- **단계**: Agent 설계 후
- **내용**: 데이터 모델, 스키마, ERD
- **템플릿**: `data_design.md.j2` (예정)

### 5. API 설계서 (API Design)
- **단계**: Agent 설계 후
- **내용**: REST API 엔드포인트, 요청/응답 스키마
- **템플릿**: `api_design.md.j2` (예정)

### 6. 에이전트 설계서 (Agent Design) ✅
- **단계**: Agent/Task 설계 후
- **내용**: Agent 역할, 목표, 할당된 도구, Task workflow
- **템플릿**: `agent_design.md.j2`

### 7. 테스트 계획서 (Test Plan)
- **단계**: 코드 생성 전
- **내용**: 테스트 전략, 시나리오, 예상 결과
- **템플릿**: `test_plan.md.j2` (예정)

### 8. 배포 가이드 (Deployment Guide)
- **단계**: 코드 생성 후
- **내용**: 배포 절차, 환경 설정, 실행 방법
- **템플릿**: `deployment_guide.md.j2` (예정)

## 설정 방법

### 1. 환경 변수 설정 (.env)

```bash
# 산출물 생성 활성화
ARTIFACT_GENERATION_ENABLED=true

# 출력 포맷 (markdown, html, pdf, json)
ARTIFACT_OUTPUT_FORMAT=markdown

# 출력 디렉토리
ARTIFACT_OUTPUT_DIR=./artifacts
```

### 2. 코드에서 설정

```python
from app.artifacts import ArtifactGenerationConfig, ArtifactGenerator

# 설정 생성
config = ArtifactGenerationConfig(
    enabled=True,

    # 생성할 산출물 선택
    generate_project_proposal=True,
    generate_requirements_spec=True,
    generate_architecture_design=True,
    generate_data_design=True,
    generate_api_design=False,          # 선택적
    generate_agent_design=True,
    generate_test_plan=False,           # 선택적
    generate_deployment_guide=False,    # 선택적

    # 출력 설정
    output_format="markdown",
    output_directory="./artifacts",

    # 추가 옵션
    include_diagrams=True,
    include_code_samples=True,
    language="ko",
)

# Generator 생성
generator = ArtifactGenerator(config=config)
```

## 사용 방법

### 방법 1: 단일 산출물 생성

```python
from app.artifacts import ArtifactGenerator, ArtifactType

generator = ArtifactGenerator(config=config)

# 프로젝트 기획서 생성
artifact = generator.generate_artifact(
    artifact_type=ArtifactType.PROJECT_PROPOSAL,
    context={
        "requirement": "기업 동향 분석 시스템 개발",
        "description": "AI 에이전트 기반 자동화 시스템",
    },
    project_name="CompanyAnalysisSystem",
)

print(f"Generated: {artifact.metadata.title}")
print(f"File: {artifact.file_path}")
```

### 방법 2: 모든 산출물 한번에 생성

```python
# 모든 활성화된 산출물 생성
artifacts = generator.generate_all_artifacts(
    project_name="CompanyAnalysisSystem",
    requirement="기업 동향 분석 시스템",
    golden_data=golden_data,      # 요구사항 분석 결과
    bmad_mapping=bmad_mapping,    # BMAD 매핑 결과
    agents=agents,                # Agent 목록
    tasks=tasks,                  # Task 목록
)

for artifact in artifacts:
    print(f"✓ {artifact.metadata.title}")
    print(f"  -> {artifact.file_path}")
```

## 템플릿 커스터마이징

산출물 템플릿은 Jinja2 형식으로 작성되어 있으며, `data/templates/artifacts/` 디렉토리에서 수정할 수 있습니다.

### 템플릿 위치
- `data/templates/artifacts/project_proposal.md.j2`
- `data/templates/artifacts/requirements_spec.md.j2`
- `data/templates/artifacts/agent_design.md.j2`
- 기타...

### 템플릿 변수

템플릿에서 사용 가능한 변수:

```jinja2
{{ metadata.title }}              - 산출물 제목
{{ metadata.version }}            - 버전
{{ metadata.created_at }}         - 생성 시각
{{ requirement }}                 - 원본 요구사항
{{ golden_data }}                 - Golden Data (요구사항 분석)
{{ agents }}                      - Agent 목록
{{ tasks }}                       - Task 목록
{{ config.include_diagrams }}     - 다이어그램 포함 여부
```

### 커스텀 템플릿 추가

```python
# 새 템플릿 파일 생성
# data/templates/artifacts/custom_artifact.md.j2

# 코드에서 사용
artifact = generator.generate_artifact(
    artifact_type=ArtifactType.CUSTOM,  # 커스텀 타입 정의 필요
    context={"key": "value"},
    project_name="MyProject",
)
```

## 통합 예제

### 전체 워크플로우에 통합

```python
from app.concretization import ConcretizationEngine
from app.core.bmad.mapper import BMADMapper
from app.artifacts import ArtifactGenerator, ArtifactGenerationConfig

# 1. 설정
artifact_config = ArtifactGenerationConfig(enabled=True)
artifact_generator = ArtifactGenerator(config=artifact_config)

# 2. 요구사항 분석
concretization_engine = ConcretizationEngine()
golden_data = concretization_engine.concretize(
    requirement="기업 동향 분석 시스템"
)

# 3. BMAD 매핑
bmad_mapper = BMADMapper()
bmad_result = bmad_mapper.map_requirement_to_bmad(
    golden_data=golden_data
)

# 4. 산출물 생성
artifacts = artifact_generator.generate_all_artifacts(
    project_name="CompanyAnalysisSystem",
    requirement="기업 동향 분석 시스템",
    golden_data=golden_data.model_dump(),
    bmad_mapping={
        "agents": bmad_result.agents,
        "tasks": bmad_result.tasks,
    },
    agents=[agent.model_dump() for agent in bmad_result.agents],
    tasks=[task.model_dump() for task in bmad_result.tasks],
)

print(f"✅ Generated {len(artifacts)} artifacts")
```

## 활용 사례

### 1. 품질 검증
각 단계별 산출물을 검토하여 프로젝트 품질을 확인합니다.

### 2. 문서화 자동화
수동으로 작성해야 하는 문서를 자동으로 생성하여 시간을 절약합니다.

### 3. 커뮤니케이션
생성된 산출물을 팀원이나 이해관계자와 공유합니다.

### 4. 아카이빙
프로젝트 이력을 문서로 보존합니다.

## 제한 사항

1. **템플릿 의존성**: 일부 산출물 타입은 템플릿이 아직 제공되지 않을 수 있습니다.
2. **포맷 지원**: 현재 Markdown 포맷만 완전히 지원됩니다.
3. **다이어그램**: Mermaid 다이어그램 지원 (일부 산출물만)

## 트러블슈팅

### Q1. 산출물이 생성되지 않아요
```python
# enabled가 True인지 확인
config = ArtifactGenerationConfig(enabled=True)

# 또는 환경 변수 확인
export ARTIFACT_GENERATION_ENABLED=true
```

### Q2. 템플릿을 찾을 수 없다는 에러가 나요
템플릿 파일이 `data/templates/artifacts/` 디렉토리에 있는지 확인하세요. 없으면 Fallback 산출물이 생성됩니다.

### Q3. 출력 디렉토리를 변경하고 싶어요
```python
config = ArtifactGenerationConfig(
    output_directory="./my_custom_dir"
)
```
