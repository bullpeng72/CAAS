# 📊 진행상황 추적 가이드

CAAS의 포괄적인 진행상황 보고 시스템 사용 가이드입니다.

**최종 업데이트**: 2026-01-31

---

## 개요

CAAS 프레임워크는 BMAD 워크플로우 실행에 대한 실시간 가시성을 제공하는 진행상황 보고 시스템을 포함합니다:

- Phase 전환 (Concretization, Discovery, Architecture, Design, Development, Delivery)
- Agent 실행 (RequirementAnalyst, SystemArchitect, AgentDesigner, CodeGenerator, QASpecialist)
- 검증 결과 및 피드백 루프
- 전체 워크플로우 진행률 및 통계

---

## 주요 기능

### ✨ 핵심 기능

1. **5단계 상세 수준**: 조용한 모드(에러만)부터 디버그(모든 것)까지
2. **Rich 콘솔 출력**: 진행 표시기가 있는 컬러풀한 포맷 출력
3. **Phase 추적**: 시작/완료/스킵 단계 및 소요 시간 추적
4. **Agent 모니터링**: 에이전트 작업, 반복, 완료 추적
5. **검증 보고**: 검증 결과, 이슈, 수정 표시
6. **피드백 루프 가시성**: 반복적 정제 프로세스 모니터링
7. **워크플로우 요약**: 통계가 포함된 최종 요약 테이블

### 🎨 출력 모드

- **Rich 모드** (기본): Rich 라이브러리를 사용한 컬러풀한 출력
- **Plain 모드**: Rich 지원이 없는 환경을 위한 단순 텍스트 출력

## 상세 수준 (Verbosity Levels)

### 1. QUIET (레벨 0)
**사용 사례**: 자동화 시스템, CI/CD 파이프라인

```bash
caas generate --verbosity quiet "할일 관리자 만들기"
```

**표시**:
- ❌ 치명적 오류만

**출력 예시**:
```
[ERROR] BMAD Workflow failed: LLM connection timeout
```

## 사용 예시

### 1. CLI 사용

```bash
# 기본 상세 수준 사용 (NORMAL)
caas generate "블로그 플랫폼 만들기"

# 스크립트용 조용한 모드
caas generate --verbosity quiet "챗봇 만들기"

# 상세 모니터링용 Verbose
caas generate --verbosity verbose "전자상거래 스토어 만들기"

# 트러블슈팅용 Debug
caas generate --verbosity debug "데이터 파이프라인 만들기"
```

### 2. Python API 사용

```python
from caas_framework.bmad.engine import BMADEngine
from caas_framework.reporting import ProgressReporter, VerbosityLevel
from caas_framework.plugins.llm.openai_plugin import OpenAIPlugin

# 원하는 상세 수준으로 진행상황 리포터 생성
reporter = ProgressReporter(
    verbosity=VerbosityLevel.VERBOSE,
    use_rich=True  # 컬러풀한 출력
)

# LLM 초기화
llm = OpenAIPlugin(model="gpt-4o-mini")

# 진행상황 보고를 포함한 BMAD 엔진 생성
engine = BMADEngine(
    llm_plugin=llm,
    progress_reporter=reporter,
    verbosity=VerbosityLevel.VERBOSE
)

# 워크플로우 실행 - 진행상황이 자동으로 보고됨
result = await engine.run(
    requirement="할일 관리 시스템 만들기",
    domain="productivity"
)
```

### 3. 커스텀 리포터 설정

```python
from caas_framework.reporting import ProgressReporter, VerbosityLevel

# Rich 모드 (컬러풀, 포맷팅)
reporter = ProgressReporter(
    verbosity=VerbosityLevel.NORMAL,
    use_rich=True
)

# Plain 모드 (단순 텍스트)
reporter = ProgressReporter(
    verbosity=VerbosityLevel.NORMAL,
    use_rich=False
)

# 프로그래밍 방식 보고
reporter.start_workflow("Custom Workflow", total_phases=5)
reporter.start_phase("Phase 1", "MyAgent", "작업 수행 중")
reporter.agent_working("MyAgent", "데이터 처리 중")
reporter.agent_completed("MyAgent", duration=10.5, iterations=1)
reporter.complete_phase("Phase 1", duration=11.2, success=True)
reporter.complete_workflow(success=True, summary={
    "total_duration": 60.5,
    "phases_completed": 5
})
```

## 출력 구성요소

### Phase 진행상황

```
📌 Phase 3: Design [AgentDesigner]
   에이전트 및 태스크 설계 중
   ✅ 15.8초 만에 완료
```

- **Phase 번호 및 이름**: 현재 BMAD phase
- **Agent 이름**: 활성 전문 에이전트
- **설명**: Phase가 하는 일
- **소요 시간**: 완료 시간

### Agent 실행

```
🤖 AgentDesigner
   ⚙️  초기 작업 시작
   ✅ 15.2초 만에 완료 (1회 반복)
```

- **Agent 이름**: 작업 중인 전문 에이전트
- **상태**: 작업 중/완료
- **소요 시간**: 실행 시간
- **반복**: 시도/정제 횟수

### 검증 결과

```
🔍 Validation: Design Validation (3 agents, 8 tasks)
   ✅ Design Validator: 통과 (0개 이슈)
```

- **검증 이름**: 검증 대상
- **결과**: 통과/실패
- **이슈 수**: 발견된 문제 수

### 피드백 루프

```
🔄 Feedback Loop: AgentDesigner [2/3]
   🔄 검증 피드백을 기반으로 출력 정제 중
```

- **Agent 이름**: 작업을 정제하는 에이전트
- **반복**: 현재/최대 반복 수
- **작업**: 진행 중인 작업

## 설정

### 환경 변수

```bash
# 기본 상세 수준 설정
export CAAS_VERBOSITY=verbose

# Rich 비활성화 (평문 텍스트 사용)
export CAAS_NO_COLOR=1
```

### 설정 파일 (~/.caas/config.yaml)

```yaml
# 기본 상세 수준
verbosity: normal  # quiet, minimal, normal, verbose, debug

# 컬러풀한 출력을 위해 Rich 사용
use_rich_console: true

# 진행상황 보고 옵션
progress:
  show_phase_duration: true
  show_agent_iterations: true
  show_validation_details: true
  show_feedback_loops: true
```

## 모범 사례

### 1. 적절한 상세 수준 선택

- **프로덕션/CI**: `quiet` 또는 `minimal` 사용
- **개발**: `normal` 사용 (기본값)
- **디버깅**: `verbose` 또는 `debug` 사용
- **데모**: `normal` 또는 `verbose` 사용

### 2. 성능 고려사항

- 높은 상세 수준도 최소한의 오버헤드 추가 (~1-2% for DEBUG)
- Rich 콘솔 출력이 효율적이고 최적화됨
- Plain 모드는 Rich를 사용할 수 없는 경우 약간 더 빠름

### 3. 로깅 통합

진행상황 보고는 표준 로깅과 함께 작동합니다:

```python
import logging

# 로깅 설정
logging.basicConfig(level=logging.INFO)

# 진행상황 리포터는 독립적으로 실행
reporter = ProgressReporter(verbosity=VerbosityLevel.NORMAL)
```

## 문제 해결

### 문제: 컬러 출력이 없음

**해결책**: Rich가 설치되었는지 확인
```bash
pip install rich
```

또는 Rich 비활성화:
```python
reporter = ProgressReporter(use_rich=False)
```

### 문제: 출력이 너무 많음

**해결책**: 상세 수준 낮추기
```bash
caas generate --verbosity minimal "..."
```

### 문제: Phase 정보 누락

**해결책**: 상세 수준 높이기
```bash
caas generate --verbosity verbose "..."
```

## 마이그레이션 가이드

기존 BMADEngine을 사용하는 코드가 있다면:

### Before
```python
engine = BMADEngine(
    llm_plugin=llm,
    enable_validation=True
)
```

### After (진행상황 보고 포함)
```python
from caas_framework.reporting import ProgressReporter, VerbosityLevel

reporter = ProgressReporter(verbosity=VerbosityLevel.NORMAL)

engine = BMADEngine(
    llm_plugin=llm,
    enable_validation=True,
    progress_reporter=reporter
)
```

리포터가 제공되지 않으면 프레임워크가 자동으로 기본 리포터를 생성하므로, 기존 코드는 변경 없이 계속 작동합니다!
