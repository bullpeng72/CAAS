## 2. API 엔드포인트


### 2.1 사용자가 새로운 할일을 추가하도록 처리

**엔드포인트**: `POST /api/v1/add_task`

**설명**: 사용자가 새로운 할일을 추가하도록 처리

**Request**:
```json
{
  "input": "string",
  "options": {}
}
```

**Response**:
```json
{
  "status": "success",
  "data": 새로운 할일이 성공적으로 추가됨,
  "message": "string"
}
```

**Status Codes**:
- `200 OK`: 성공
- `400 Bad Request`: 잘못된 요청
- `401 Unauthorized`: 인증 실패
- `500 Internal Server Error`: 서버 오류

---


### 2.2 사용자가 할일 목록을 조회하도록 처리

**설명**: 사용자가 할일 목록을 조회하도록 처리

**Request**:
```json
{
  "input": "string",
  "options": {}
}
```

**Response**:
```json
{
  "status": "success",
  "data": 사용자의 모든 할일 목록,
  "message": "string"
}
```

**Status Codes**:
- `200 OK`: 성공
- `400 Bad Request`: 잘못된 요청
- `401 Unauthorized`: 인증 실패
- `500 Internal Server Error`: 서버 오류

## 3. 공통 요소

### 3.1 인증

**Header**:
```
Authorization: Bearer {token}
```

### 3.2 응답 형식

```json
{
  "status": "success|error",
  "data": {},
  "message": "string",
  "timestamp": "ISO 8601"
}
```

### 3.3 에러 응답

```json
{
  "status": "error",
  "error": {
    "code": "ERROR_CODE",
    "message": "Human readable message"
  }
}
```
