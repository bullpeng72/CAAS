## 2. API 엔드포인트


### 2.1 사용자가 제목, 설명, 마감일 및 우선 순위를 입력하여 새로운 작업을 생성한다.

**엔드포인트**: `POST /api/v1/create_task`

**설명**: 사용자가 제목, 설명, 마감일 및 우선 순위를 입력하여 새로운 작업을 생성한다.

**Request**:
```json
{
  "input": "string",
  "options": {}
}
```

**Response**:
```json
{
  "status": "success",
  "data": 작업이 성공적으로 생성되었음을 알리는 확인 메시지,
  "message": "string"
}
```

**Status Codes**:
- `200 OK`: 성공
- `400 Bad Request`: 잘못된 요청
- `401 Unauthorized`: 인증 실패
- `500 Internal Server Error`: 서버 오류

---


### 2.2 사용자가 모든 작업의 목록을 조회할 수 있도록 하여 각 작업의 상태 및 세부정보를 표시한다

**엔드포인트**: `POST /api/v1/view_tasks`

**설명**: 사용자가 모든 작업의 목록을 조회할 수 있도록 하여 각 작업의 상태 및 세부정보를 표시한다.

```json
}
```

```json
{
  "status": "success",
```

## 3. 공통 요소

### 3.1 인증

**Header**:
```
Authorization: Bearer {token}
```

### 3.2 응답 형식

```json
{
  "status": "success|error",
  "data": {},
  "message": "string",
  "timestamp": "ISO 8601"
}
```

### 3.3 에러 응답

```json
{
  "status": "error",
  "error": {
    "code": "ERROR_CODE",
    "message": "Human readable message"
  }
}
```
