## 2. API 엔드포인트


### 2.1 사용자의 등록 정보를 수집하고 유효성을 검증하여 새로운 사용자를 등록합니다.

**엔드포인트**: `POST /api/v1/task_user_registration`

**설명**: 사용자의 등록 정보를 수집하고 유효성을 검증하여 새로운 사용자를 등록합니다.

**Request**:
```json
{
  "input": "string",
  "options": {}
}
```

**Response**:
```json
{
  "status": "success",
  "data": 사용자 등록 성공 또는 실패 메시지,
  "message": "string"
}
```

**Status Codes**:
- `200 OK`: 성공
- `400 Bad Request`: 잘못된 요청
- `401 Unauthorized`: 인증 실패
- `500 Internal Server Error`: 서버 오류

---


### 2.2 사용자의 이메일과 비밀번호를 검증하여 로그인 절차를 수행합니다.

**엔드포인트**: `POST /api/v1/task_user_login`

**설명**: 사용자의 이메일과 비밀번호를 검증하여 로그인 절차를 수행합니다.

**Request**:
```json
{
  "input": "string",
  "options": {}
}
```

**Response**:
```json
{
  "status": "success",
  "data": 로그인 성공 시 JWT 토큰, 실패 시 오류 메시지,
  "message": "string"
}
```

**Status Codes**:
- `200 OK`: 성공
- `400 Bad Request`: 잘못된 요청
- `401 Unauthorized`: 인증 실패
- `500 Internal Server Error`: 서버 오류

---

**설명**: 로그인 성공 시 사용자의 ID를 기반으로 JWT 토큰을 생성합니다.

## 3. 공통 요소

### 3.1 인증

**Header**:
```
Authorization: Bearer {token}
```

### 3.2 응답 형식

```json
{
  "status": "success|error",
  "data": {},
  "message": "string",
  "timestamp": "ISO 8601"
}
```

### 3.3 에러 응답

```json
{
  "status": "error",
  "error": {
    "code": "ERROR_CODE",
    "message": "Human readable message"
  }
}
```
