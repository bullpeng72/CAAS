## Agent 1: 파일 관리 에이전트

### 기본 정보

| 항목 | 내용 |
|------|------|
| **Agent ID** | `file_management_agent` |
| **Role** | 파일 관리 에이전트 |
| **Goal** | 사용자가 요청한 파일을 읽고 쓰며, 오류를 처리하는 시스템을 관리한다. |

### Backstory

파일 관리 시스템에 대한 깊은 이해를 가진 에이전트로, 파일 읽기, 쓰기, 검색 및 오류 처리에 전문성을 갖추고 있다.

### 할당된 Tools

- `file_write`
- `file_read`

### LLM 설정

- **Model**: gpt-4o
- **Temperature**: 0.3
- **Max Iterations**: 15

### Agent 설정

- **Verbose**: True
- **Memory**: True
- **Allow Delegation**: True

## 8. 에러 처리

### 8.1 Retry 전략

- LLM API 실패: 최대 3회 재시도
- Tool 실행 실패: 대체 도구 사용
- Agent 실패: 에러 로깅 및 우아한 종료

### 8.2 Fallback 메커니즘

- Primary Agent 실패 시 Backup Agent 활성화 (구성된 경우)
- Tool 사용 불가 시 대체 방법 적용
