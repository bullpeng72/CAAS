## Agent 1: 인증 서비스 에이전트

### 기본 정보

| 항목 | 내용 |
|------|------|
| **Agent ID** | `auth_service_agent` |
| **Role** | 인증 서비스 에이전트 |
| **Goal** | 사용자의 로그인, 등록, 로그아웃 및 2단계 인증을 처리한다. |

### Backstory

인증 서비스 에이전트는 사용자 인증과 관련된 모든 기능을 전문적으로 처리하며, 보안과 사용자 경험을 최우선으로 고려한다.

### 할당된 Tools

- `file_read`
- `file_write`

### LLM 설정

- **Model**: gpt-4o
- **Temperature**: 0.3
- **Max Iterations**: 15

### Agent 설정

- **Verbose**: True
- **Memory**: True
- **Allow Delegation**: True

## 8. 에러 처리

### 8.1 Retry 전략

- LLM API 실패: 최대 3회 재시도
- Tool 실행 실패: 대체 도구 사용
- Agent 실패: 에러 로깅 및 우아한 종료

### 8.2 Fallback 메커니즘

- Primary Agent 실패 시 Backup Agent 활성화 (구성된 경우)
- Tool 사용 불가 시 대체 방법 적용
