## 2. API 엔드포인트


### 2.1 사용자가 이메일과 비밀번호를 사용하여 로그인할 수 있도록 처리한다.

**엔드포인트**: `POST /api/v1/task_login`

**설명**: 사용자가 이메일과 비밀번호를 사용하여 로그인할 수 있도록 처리한다.

**Request**:
```json
{
  "input": "string",
  "options": {}
}
```

**Response**:
```json
{
  "status": "success",
  "data": 사용자가 성공적으로 로그인하거나 오류 메시지를 받는다.,
  "message": "string"
}
```

**Status Codes**:
- `200 OK`: 성공
- `400 Bad Request`: 잘못된 요청
- `401 Unauthorized`: 인증 실패
- `500 Internal Server Error`: 서버 오류

## 3. 공통 요소

### 3.1 인증

**Header**:
```
Authorization: Bearer {token}
```

### 3.2 응답 형식

```json
{
  "status": "success|error",
  "data": {},
  "message": "string",
  "timestamp": "ISO 8601"
}
```

### 3.3 에러 응답

```json
{
  "status": "error",
  "error": {
    "code": "ERROR_CODE",
    "message": "Human readable message"
  }
}
```
